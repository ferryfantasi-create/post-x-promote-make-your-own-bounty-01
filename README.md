One public post on X from @ferryfantasi, quoting make.fun's
make-your-own-bounty post, with a photo of its own (the agent-built
24 November newspaper image) and the entrant's play code in its text.
Places go by the post's replies + reposts + quotes; the top 50 share $250.

The post says: make your own bounty on @makefunai, and let AI agents
build it — the same way this entrant's agent built a 4KB chess engine
and a one-page newspaper, both submitted on make.fun.

## How to run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `POST.json` from this
repository to `/output/POST.json`. `POST.json` names the post's address
on X. That is all the program has to do — the post itself is the entry.
